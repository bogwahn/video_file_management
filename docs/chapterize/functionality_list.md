# Chapterize Functionality List

## Functionality

1. **Read BookmarksFile** - Ability to read bookmark file information from a text file using the appropriate reader.
2. **Write BookmarksFiles** - Ability to write bookmark information to a bookmarks file using the appropriate writer.
3. **Read ChaptersFile** - Ability to read chapter file information from a text file using the appropriate reader.
4. **Write ChaptersFiles** - Ability to write chapter information to a chapters file using the appropriate writer.
5. **Read VideoMetadata** - Ability to read video metadata information from a video file, including resolution, duration, codecs, and other relevant properties. This includes chapter information.
6. **Manage Chapters** - Ability to add, remove, and modify chapters within a video file.
7. **Manage Tags** - Ability to add, remove, and modify tags associated with a video file. This includes Finder tags.
